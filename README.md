# UX톤 적용하기 - Figma 플러그인

한국어 UX Writing을 친근한 톤으로 자동 변환해주는 Figma 플러그인입니다.

## ✨ 주요 기능

- **텍스트 톤 분석**: 선택한 텍스트의 문체, 감정, 키워드를 분석
- **자동 변환**: 격식체를 친근한 UX Writing 톤으로 변환
- **선택적 적용**: 권장 변경사항을 미리 보고 선택적으로 적용
- **실시간 프리뷰**: 변경 전후 비교 및 실시간 미리보기

## 🎯 변환 규칙

### 행동 유도 패턴
| 기존 표현 | 변환 후 | 효과 |
|----------|---------|------|
| 확인해보세요 | 확인하기 | 친근한 어조 |
| 이용해보세요 | 이용하기 | 간결한 표현 |
| 참여해보세요 | 참여하기 | 직접적 유도 |
| 신청해보세요 | 신청하기 | 간편함 강조 |
| 문의해보세요 | 문의하기 | 쉬운 접근 |

### 격식체 → 친근한 표현
| 기존 표현 | 변환 후 | 효과 |
|----------|---------|------|
| 됩니다 | 돼요 | 친근한 확인 |
| 입니다 | 이에요 | 부드러운 설명 |
| 있습니다 | 있어요 | 친근한 안내 |
| 습니다 | 어요 | 격식체를 친근하게 |

### 조건문 및 요청 표현
| 기존 표현 | 변환 후 | 효과 |
|----------|---------|------|
| 하시면 | 하면 | 간결한 조건 |
| 하십시오 | 해주세요 | 정중한 요청 |

## 🚀 설치 방법

### 1. 개발 환경 설정

```bash
# 저장소 클론
git clone <repository-url>
cd ux-tone-plugin

# 의존성 설치
npm install

# TypeScript 빌드
npm run build
```

### 2. Figma에 플러그인 추가

1. Figma 데스크톱 앱 실행
2. `Plugins` > `Development` > `Import plugin from manifest...` 클릭
3. 프로젝트 폴더의 `manifest.json` 파일 선택

## 📖 사용 방법

### 기본 사용법

1. Figma에서 텍스트 레이어 선택
2. `Plugins` > `Development` > `ux톤 적용하기` 실행
3. 플러그인 패널에서 분석 결과 확인
4. 원하는 변경사항 선택 후 "적용하기" 클릭

### UI 구성

#### 📄 원본 텍스트
- 선택한 텍스트 노드의 내용을 표시

#### 🎯 톤 프로파일
- **현재 톤**: 텍스트의 전체적인 톤 분류
- **문장 길이**: 텍스트의 문자 수
- **문장 유형**: 서술문, 의문문, 명령문, 감탄문
- **감정 톤**: 중립적, 열정적, 친근함, 전문적, 장난스러운
- **감정 강도**: 감정 표현의 강도 점수
- **변환 적용률**: 전체 텍스트 대비 변환 가능한 비율
- **주요 키워드**: 추출된 핵심 키워드들

#### ✨ 권장 변경사항
- 적용 가능한 톤 변환 규칙들을 표시
- 체크박스로 선택적 적용 가능
- 변경 전 → 변경 후 미리보기

## 🛠 개발

### 프로젝트 구조

```
ux-tone-plugin/
├── src/
│   └── code.ts          # 메인 플러그인 로직
├── ui.html              # 사용자 인터페이스
├── manifest.json        # 플러그인 매니페스트
├── package.json         # 프로젝트 설정
├── tsconfig.json        # TypeScript 설정
└── README.md            # 문서
```

### 개발 명령어

```bash
# TypeScript 컴파일
npm run build

# 파일 변경 감지 및 자동 컴파일
npm run watch

# 린팅 (ESLint 설정 시)
npm run lint
```

### 개발 워크플로우

1. `src/code.ts` 파일에서 로직 수정
2. `ui.html` 파일에서 UI 수정
3. `npm run build` 또는 `npm run watch` 실행
4. Figma에서 플러그인 테스트

## 🎨 UI 디자인

플러그인 UI는 Shadcn 스타일을 참고하여 제작되었습니다:

- **모던한 디자인**: 깔끔하고 직관적인 인터페이스
- **반응형 레이아웃**: 다양한 패널 크기에 대응
- **시각적 피드백**: 호버, 선택 상태 등의 상호작용 효과
- **접근성**: 키보드 내비게이션 및 스크린 리더 지원

## 🔧 기술 스택

- **TypeScript**: 타입 안전성과 개발 경험 향상
- **Figma Plugin API**: 텍스트 노드 조작 및 UI 통신
- **Vanilla HTML/CSS/JS**: 가벼운 UI 구현
- **정규 표현식**: 텍스트 패턴 매칭 및 변환

## 📊 분석 로직

### 문장 타입 분석
- **의문문**: '?', '까요' 포함
- **명령문**: '!', '세요', '하기' 포함
- **감탄문**: '!' 포함
- **서술문**: 기본값

### 감정 톤 분석
- **열정적**: '설렘', '최고', '특가', '대박', '놀라운', '환상', '완벽', '!' 등
- **친근함**: '함께', '나만의', '여러분', '편안', '따뜻', '어요', '이에요' 등
- **전문적**: '서비스', '품질', '전문', '안전', '신뢰', '보장', '관리' 등
- **장난스러운**: '재미', '즐거운', 'ㅋ', '귀여운', '신나는', '웃음' 등
- **중립적**: 특별한 감정 키워드가 없는 경우

### 키워드 추출
- 공백 기준 단어 분리
- 2글자 이상 단어 필터링
- 최대 5개 키워드 추출

## 🚀 확장 가능성

### 규칙 추가
`TONE_RULES` 배열에 새로운 변환 규칙을 쉽게 추가할 수 있습니다:

```typescript
{
  pattern: /새로운패턴/g,
  replacement: '변환결과',
  description: '변환 규칙 설명'
}
```
